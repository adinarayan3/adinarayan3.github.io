`Abstract:`
Sensory reactivation in early visual cortex occurs during both working memory and long-term memory tasks. We speculated that the control mechanisms originating from higher order brain areas differ between these two types of memory, with the hippocampus exerting more influence on long-term memory and prefrontal cortex on working memory. To test this, we examined fMRI response patterns in the visual cortex during both tasks as a function of response amplitude in the hippocampus and prefrontal cortex. Our results demonstrate a dissociation: hippocampal response amplitude is strongly linked to long-term memory responses in V1, V2, and V3, and prefrontal cortex amplitude is linked to working memory responses in V1. 

`Keywords`: long-term memory; working memory; hippocampus; prefrontal cortex
